2. STATION NAMES WITH A QUOTE: string building vs ? placeholder
======================================================================

input: 'Adyar'
   + version  SQL  : SELECT AVG(pm25) FROM aq WHERE station = 'Adyar'
   + version  gives: 54.0
   ? version  gives: 54.0

input: "St. Mary's Road"
   + version  FAILED: OperationalError: near "s": syntax error
   ? version  gives: 70.0

input: "Adyar' OR '1'='1"
   + version  SQL  : SELECT AVG(pm25) FROM aq WHERE station = 'Adyar' OR '1'='1'
   + version  gives: 78.8
   ? version  gives: None

Reading the results:
  - the real name 'St. Mary's Road' breaks the + version (the quote ends the string early)
    but works with ?, because the value is never pasted into the SQL text
  - the injection text changes the meaning of the + query: it returns the average of ALL rows
    (data the user should not be able to reach); with ? it is just a station name that does
    not exist, so the answer is None
  - sqlite3's execute() refuses stacked statements: ProgrammingError: You can only execute one statement at a time.

executemany() vs execute() in a loop (in-memory table, one commit at the end):
      rows       loop  executemany
     10000     0.010s       0.005s
    100000     0.091s       0.059s
    500000     0.546s       0.268s
  both are O(n); executemany is faster by a constant factor because the loop pays Python call
  overhead for every row
