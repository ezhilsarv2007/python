# CSA08 – Python Programming Assignment 4 (CO4)

Humanised, beginner-friendly Python programs for file handling, exceptions, modules and packages.

## Requirements
- Python 3.10 or later
- Python standard library only; no third-party packages

## Folder contents
- `Task01` – mess-bill file processing and rejected-record logging
- `Task02` – monthly attendance reports from daily files
- `Task03` – custom exception and complete attendance parser
- `Task04` – append-mode library return log and error log
- `Task05` – same attendance utility organised in four ways
- `Task06` – college fest registration package

Each task has input files (where needed), source code, an `answer.txt` design note and an `output` folder containing generated reports and `console_output.txt`.

## Run the programs
Run these commands from this folder:
```bash
python Task01/main.py
python Task02/main.py
python Task03/main.py
python Task04/main.py
python Task05/single_script/main.py
python Task05/one_module/main.py
python Task05/three_modules/main.py
python Task05/package/main.py
python Task06/main.py
```

Before submitting, add your name, register number, Python version and GitHub repository link. Run each program on your own computer and make sure you can explain the code during verification.
