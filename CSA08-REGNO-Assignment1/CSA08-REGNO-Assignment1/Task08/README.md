## Alternative concept - running total vs stored list
Both are O(n) time. Extra space: running total **O(1)** (0.9 KB peak at every n), stored list **O(n)** (33 KB, 662 KB, 16.5 MB for n = 300, 6,000, 150,000). Storing is still necessary when individual payments are needed afterwards (statements, bank file, audits, recalculation).
