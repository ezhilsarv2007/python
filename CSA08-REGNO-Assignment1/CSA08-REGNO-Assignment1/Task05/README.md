# Task 5 - Read Input and Convert Types (K3)

**Run:** `python task05_input.py` (prepared demo)  or  `python task05_input.py --live` (type real values with `input()`)

## Key points
* `input()` always returns a **string**; convert with `float()` / `int()`. `int("8.5")` raises `ValueError`; `"8.5" * 2` repeats text.
* `"8,5"` and `"eight"` raise `ValueError` in `float()`; they are also rejected by the string-method check.
* **Method 1 (check first):** strip spaces, drop one sign, allow at most one `.`, then `replace(".", "", 1).isdigit()`.
* **Method 2 (try/except ValueError):** shorter, but `float()` also accepts `'nan'`, `'inf'`, `'1e2'`, `'1_0'`, so a range test is still needed.
* Formatted output: `{amount:11.2f}` (width 11, 2 decimals), `{name:<8}` (left aligned), `{x:,.2f}` (thousands separator).

## Alternative concept - timing (200,000 calls)
Both are O(1) per entry. try/except is fastest for valid text (~80 ns) but slowest for invalid text (~400-640 ns) because raising an exception is expensive; the str check costs about the same either way (~230-350 ns).
