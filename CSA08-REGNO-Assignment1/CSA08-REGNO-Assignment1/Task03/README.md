# Task 3 - Choose Variables and Name the Constants (K3)

**Run:** `python task03_constants.py` (uses `rates.py`, the single place for every rate and limit)

## Key points
* **Naming:** letters/digits/underscore, cannot start with a digit, no spaces or reserved words; `snake_case` for variables and functions, `UPPER_CASE` for constants.
* **No true constants in Python:** `rates.BASE_RATE = 99.0` is accepted without error - only the UPPER_CASE convention (and linters/`typing.Final`) protect a constant.
* **Dynamic typing:** the same name can hold int, then str, then float; `8 + "5"` raises `TypeError`.
* **Multiple assignment / swap:** `fat, snf = snf, fat`; chained `low = high = 0`; unpacking `a, *rest = [...]`.

## Alternative concept - magic numbers vs dictionary vs constants
All three give the same rate (33.4) and each call takes about the same time (O(1)); memory is O(1).
* Magic numbers: a revision must be made in **k places** - miss one and the revision is applied partly (the volunteer's bug).
* `RATE_CARD` dictionary: 1 place, but a mistyped key fails only at run time (`KeyError`).
* Named constants: 1 place, a mistyped name fails immediately.
